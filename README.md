# NexHire Job & Career Board

NexHire is a MERN job and career board with separate student and company portals.

## Project structure

- `frontend/` contains the Vite React application and JSX source.
- `backend/` contains the Express server, database abstraction, and API routes.
- `dist/` is generated by the production build.

## Run locally

Prerequisite: Node.js

```bash
npm install
npm run dev
```

The development server runs the Express API and Vite frontend on `http://localhost:3000`.

## Build and start

```bash
npm run build
npm start
```
